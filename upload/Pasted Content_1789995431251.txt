6. TENANT ISOLATION AUDIT
==================================================

This is a CRITICAL task.

Inspect every business-owned entity.

For each entity determine:

- Does it belong to a business?
- How is ownership represented?
- Is ownership enforced server-side?
- Can a user query another business's record by ID?
- Can a user update another business's record?
- Can a user delete another business's record?
- Can AI tools access another business's data?
- Can exports accidentally include another business's data?
- Can reports aggregate across unauthorized businesses?
- Can search return another tenant's data?
- Can API routes omit tenant authorization?
- Can server actions be called directly without proper authorization?

Test insecure direct object references such as:

/api/customers/[id]

/api/products/[id]

/api/sales/[id]

/api/expenses/[id]

etc.

Attempt cross-tenant access in tests.

Expected result:

UNAUTHORIZED ACCESS MUST FAIL.

Create automated regression tests for discovered vulnerabilities.
