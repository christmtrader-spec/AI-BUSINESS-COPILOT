============================================================
7. BASELINE STRATEGY
============================================================

The current database contains existing state that must be preserved.

Therefore establish a Prisma migration baseline.

For Prisma 6.x, the conceptual baseline workflow is:

1. Generate migration SQL from empty database to current schema.
2. Review the generated SQL.
3. Store it as an initial migration.
4. Mark the baseline as already applied to the existing database.
5. Do not execute the baseline creation SQL against the existing database.

The baseline migration must represent the CURRENT schema exactly.

Do not create a fake "minimal" baseline.
