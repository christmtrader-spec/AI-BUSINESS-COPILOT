    62→// inside the emailed link. Single active token per user is enforced in the

   551→// Prompt 20 — PLATFORM BILLING FOUNDATION (subscription + entitlement domain).
   552→//
   553→// SEPARATION LAW (docs/billing/platform-billing-vs-business-finance.md):
   554→// these tables model the SaaS subscription of a business TO THIS PLATFORM.
   555→// They must never be mixed with tenant business finance (Sale/Expense/
   556→// Payment), which records the business's OWN customers' money.
   557→//
   558→// Modeling notes:
   559→// - SQLite has no enums → status/type/period/billingPeriod are strings;

  1145→// Prompt 28 — PLATFORM CONTROL PLANE (internal operator layer).
  1146→//
  1147→// HARD DOMAIN SEPARATION (docs/security/platform-admin-security.md):
  1148→//   TENANT domain  (User/Business/BusinessMember + tenant RBAC) is a
  1149→//   completely different authority from the PLATFORM domain. A business
  1150→//   OWNER/ADMIN/... never gains platform access; a PlatformOperator gains
  1151→//   platform access ONLY through its dedicated row + role (server-derived,
  1152→//   never client-asserted).
  1153→//
  1154→// PlatformOperator:
  1155→//  - userId is UNIQUE: one operator record per user, ever.
  1156→//  - User remains the IDENTITY authority: no email/name/password here.
  1157→//  - Deleting the User CASCADES the operator record — a deleted account can
  1158→//    never leave a privileged row behind (no orphans, no silent access).
  1159→//  - active=false instantly blocks every platform API (checked on every
  1160→//    request) WITHOUT touching the user's tenant memberships (§120).
  1161→//  - Roles: PLATFORM_SUPER_ADMIN | PLATFORM_SUPPORT | PLATFORM_BILLING |
  1162→//    PLATFORM_AI_COST | PLATFORM_SECURITY | PLATFORM_READONLY (rbac in
  1163→//    src/lib/platform/rbac.ts — never the tenant role set).
  1164→//
  1165→// PlatformAuditLog:
  1166→//  - Deliberately has NO tenant-Business foreign key: platform audit must
  1167→//    survive business deletion (§9). Target references are plain indexed
  1168→//    strings, never relations.
  1169→//  - operatorId is SetNull when the operator row disappears; the role at
  1170→//    action time is snapshotted so the record stays interpretable.
  1171→//  - Content law (§10): only allowlisted safe fields; never passwords,
  1172→//    tokens, provider secrets, full AI prompts/responses or payment
  1173→//    credentials. JSON payloads are size-bounded at write time.
  1174→// ---------------------------------------------------------------------------
