   107→model MfaCredential {

   141→// ---------------------------------------------------------------------------
   142→// Prompt 30 — short-lived pre-auth MFA login challenge (§47). Password
   143→// success alone NEVER creates a session when MFA is enabled (§54): the
   144→// client receives only this bounded challenge. Hash-only storage; single
   145→// use claimed atomically (§50); bound to the user's sessionVersion so a

   549→// Phase 07 — Copilot transcript persistence (r10 rec #1).
   550→// Conversations follow the user ACROSS DEVICES: scoped per (business, user) —
   551→// a user's questions are their own, never shared across members. The client
