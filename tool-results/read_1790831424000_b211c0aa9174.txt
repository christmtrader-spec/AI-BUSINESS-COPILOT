    64→// Prompt 30 — email ownership verification (§4). ONLY the SHA-256 HASH of a

    66→// inside the emailed link. Single active token per user is enforced in the

    89→// never in the database §33/§34). enabledAt NULL = pending setup (never

    93→model MfaCredential {

   105→  createdAt        DateTime  @default(now())
   106→  updatedAt        DateTime  @updatedAt
   107→
   108→  @@index([userId, enabledAt])

  1029→//   1 currency MINOR unit = 1,000,000 NANO-MINOR units. Rates and costs are
  1030→//   BigInt nano-minor — NEVER floats, never JavaScript `number` money.
  1031→//
  1032→// Honesty model (§32/§33/§163):
  1033→//   UNKNOWN cost = NULL amount + status UNKNOWN + a stable unknownReason.
  1034→//   UNKNOWN is NEVER zero and never estimated. Historical usage keeps cost
  1035→//   UNKNOWN until a VERIFIED rate exists for its exact usage timestamp.
  1036→//
  1037→// Idempotency (§15/§31): usageEventId UNIQUE and (businessId, requestId)
  1038→// UNIQUE — a replayed attribution can never double-count cost.
  1039→// ---------------------------------------------------------------------------

  1042→  id                       String    @id @default(cuid())
  1043→  // Provider slug (e.g. "z-ai") — the provider abstraction identifier.
  1044→  provider                 String
  1045→  // EXACT model identifier as reported by the provider, or the explicit
  1046→  // reserved mapping "DEFAULT" (only where provider semantics make it
  1047→  // legitimate — never a fuzzy fallback, §33/§106).
  1048→  model                    String
  1049→  // ISO 4217 pricing currency of the RATE (provider pricing currency —
  1050→  // never assumed equal to business or settlement currency, §24).
  1051→  currency                 String
  1052→  // Immutable human version id (e.g. "2026-09-v1"). New price → new version.
  1053→  version                  String
  1054→  // nano-minor units per 1K tokens (1 minor unit = 1,000,000 nano-minor).
  1055→  inputRateNanoMinorPer1K  BigInt
  1056→  outputRateNanoMinorPer1K BigInt
  1057→  // Effective window (UTC). usageTimestamp decides which version applies —
  1058→  // no retroactive application of later rates (§104).
  1059→  effectiveFrom            DateTime

  1156→// HARD DOMAIN SEPARATION (docs/security/platform-admin-security.md):

  1163→// PlatformOperator:
  1164→//  - userId is UNIQUE: one operator record per user, ever.

  1166→//  - Deleting the User CASCADES the operator record — a deleted account can
  1167→//    never leave a privileged row behind (no orphans, no silent access).
  1168→//  - active=false instantly blocks every platform API (checked on every
  1169→//    request) WITHOUT touching the user's tenant memberships (§120).

  1172→//    src/lib/platform/rbac.ts — never the tenant role set).
  1173→//
  1174→// PlatformAuditLog:
  1175→//  - Deliberately has NO tenant-Business foreign key: platform audit must
  1176→//    survive business deletion (§9). Target references are plain indexed
  1177→//    strings, never relations.
  1178→//  - operatorId is SetNull when the operator row disappears; the role at
  1179→//    action time is snapshotted so the record stays interpretable.
  1180→//  - Content law (§10): only allowlisted safe fields; never passwords,
