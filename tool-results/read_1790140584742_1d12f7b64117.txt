   286→7. BASELINE STRATEGY
   287→============================================================
   288→
   289→The current database contains existing state that must be preserved.
   290→
   291→Therefore establish a Prisma migration baseline.
   292→
   293→For Prisma 6.x, the conceptual baseline workflow is:
   294→
   295→1. Generate migration SQL from empty database to current schema.
   296→2. Review the generated SQL.
   297→3. Store it as an initial migration.
   298→4. Mark the baseline as already applied to the existing database.
   299→5. Do not execute the baseline creation SQL against the existing database.
   300→
   301→The baseline migration must represent the CURRENT schema exactly.
   302→
   303→Do not create a fake "minimal" baseline.
